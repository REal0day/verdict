# Curated vulnerable-source test cases for the Investigations pipeline.
# Each row: name | git_url | vulnerable_ref | fixed_ref | cve | title | finding_report
# The vulnerable_ref is the release JUST BEFORE the fix, so the tree contains
# the bug and no patch. fixed_ref is for you to diff against when grading.
minimist|https://github.com/minimistjs/minimist|v1.2.2|v1.2.3|CVE-2020-7598|Prototype pollution in argument parsing|A report says this argument-parsing library is vulnerable to prototype pollution: specially crafted command-line arguments (e.g. involving __proto__) can set properties on Object.prototype, polluting every object in the process. Find where in the source the parser assigns nested keys without guarding against __proto__/constructor/prototype, and explain the exact code path.
ejs|https://github.com/mde/ejs|v3.1.6|v3.1.7|CVE-2022-29078|Server-side template injection to RCE|A report says this template engine allows remote code execution: by controlling certain render options (not just the template data), an attacker can influence how the template function is compiled and execute arbitrary code. Identify the option(s) and the code that flows them into function/compilation, and describe the RCE path.
lodash|https://github.com/lodash/lodash|4.17.11|4.17.12|CVE-2019-10744|Prototype pollution in defaultsDeep|A report says a deep-merge utility in this library is vulnerable to prototype pollution via a crafted source object that reaches __proto__. Locate the merge/defaults implementation responsible and the missing guard, and explain how Object.prototype gets polluted.
node-serialize|https://github.com/luin/serialize|master|master|CVE-2017-5941|RCE via unserialize of IIFE|A report says this serialization library executes attacker-controlled code during unserialize: a payload containing a function expression (an immediately-invoked function) is evaluated when the object is deserialized. Find the code that evaluates serialized functions and explain the remote code execution.
bottle|https://github.com/bottlepy/bottle|0.12.18|0.12.19|CVE-2020-28473|CRLF / header injection|A report says this micro web framework is vulnerable to CRLF/header injection: unsanitized input used in a response header (or redirect location) lets an attacker inject CR/LF and forge additional headers. Locate where header/redirect values are set from user input without stripping CR/LF, and explain the injection.
pyyaml|https://github.com/yaml/pyyaml|5.3.1|5.4|CVE-2020-14343|Arbitrary code execution via unsafe load|A report says this YAML library can execute arbitrary Python when loading untrusted input with the full loader: certain YAML tags (python/object, python/object/apply) instantiate arbitrary objects/call arbitrary functions. Find the loader/constructor code that resolves these tags and explain how a malicious document leads to code execution.
